## CMIN2 线路到底是什么

CMIN2 是 China Mobile International Network 2 的缩写，走的是中国移动的国际骨干网络。和 CN2 GIA（中国电信精品网）类似，CMIN2 同样属于低拥塞、高优先级的直连线路，但走的是移动的网络体系，对移动宽带用户尤其友好。

普通 BGP 线路在晚高峰会经过大量中间节点，延迟抖动明显。CMIN2 的路由路径更短，绕路少，在国内访问境外服务器时，延迟和稳定性都有明显优势。

DMIT 的 Pro 系列套餐全部采用 CMIN2 回程，部分套餐还做到了去程也走 CMIN2，双向优化。这是它区别于同价位竞品的核心卖点。

## CMIN2 和 CN2 GIA 的区别

这是很多人在选 VPS 时会纠结的问题。简单说：

**CN2 GIA** 走中国电信的精品网，对电信宽带用户最友好，延迟极低，但价格通常偏高，且部分服务商的 CN2 GIA 在高峰期也会有拥塞。

**CMIN2** 走中国移动的国际骨干网，对移动宽带用户天然友好，联通用户也有不错的表现，电信用户体验略逊于 CN2 GIA 但差距不大。

实际使用中，CMIN2 的稳定性口碑很好，尤其是 DMIT 这种专门针对 CMIN2 做了路由优化的服务商，晚高峰的表现比很多标榜 CN2 GIA 的廉价服务商要强。

## 常见问题

### DMIT 的 Pro 系列和 EB 系列有什么区别？

Pro 系列主打 CMIN2 直连，去回程都经过优化，延迟低、稳定性强，价格相对高一些。EB（Eyeball）系列价格更低，线路优化程度适中，适合预算有限、对延迟要求不那么严格的用户。

### CMIN2 线路对联通用户友好吗？

友好。CMIN2 对移动用户最优，但联通用户通过 CMIN2 的体验也明显好于普通 BGP 线路。电信用户走 CMIN2 也可以，只是相比 CN2 GIA 会有一点差距。

### 香港 Pro 的 IP 能解锁流媒体吗？

部分套餐的香港原生 IP 对 Netflix、Disney+ 等平台有解锁能力，但具体情况因 IP 段而异，不能保证 100% 解锁。购买前可以先用 Tiny 套餐测试。

### 套餐流量超出后怎么处理？

流量超出后，DMIT 通常会限速而非直接断网，具体策略以官网条款为准。如果流量需求大，建议直接选更高档位的套餐。

### 支持 IPv6 吗？

DMIT 的套餐通常提供 IPv4 + IPv6 双栈支持，具体以各套餐页面说明为准。
